<h1 align="center">🚀 Sorting-C-Language — Fun-Sized Sorting & Array Tricks in C</h1>

<p align="center">
  A compact, fun, beginner-friendly collection of sorting algorithms and small array problems.<br>
  Written fully in <strong>C</strong>, sprinkled with a bit of humor, and perfect for learning.
</p>

<hr/>

<h2>📌 What This Repo Is</h2>

<p>
This repo contains simple, clean implementations of classic sorting algorithms and some array-based problems.  
Everything is written in <strong>C</strong> (with a tiny <code>test.cpp</code> for experimenting).  
Great for practicing, comparing logic, and watching numbers magically organize themselves.
</p>

<hr/>

<h2>📂 Files & What They Do</h2>

<ul>
  <li><code>BubbleSort.c</code> — classic bubble sort. Simple and satisfying.</li>
  <li><code>EnhancedBubbleSort.c</code> — bubble sort but smarter (stops early if sorted).</li>
  <li><code>InsertionSort.c</code> — great for nearly-sorted arrays.</li>
  <li><code>SelectionSort.c</code> — find the minimum, place it, repeat. Easy to visualize.</li>
  <li><code>DuplicateElement.c</code> — finds duplicate elements using basic scanning.</li>
  <li><code>DuplicateElement2.c</code> — a second approach to find duplicates.</li>
  <li><code>TwoPointerProblem.c</code> — demonstrates the powerful two-pointer technique.</li>
  <li><code>test.cpp</code> — a small C++ playground for quick testing.</li>
  <li><code>*.exe</code> — precompiled binaries for Windows users.</li>
</ul>

<blockquote>
If you want more algorithms (MergeSort, QuickSort, HeapSort, Counting Sort, Radix Sort, etc.),  
just tell me — I’ll add them happily with sweet comments and examples.
</blockquote>

<h2>🛠️ Compile & Run</h2>

<p>Each file is standalone. To compile:</p>

```bash
gcc BubbleSort.c -o BubbleSort
gcc EnhancedBubbleSort.c -o EnhancedBubbleSort
gcc InsertionSort.c -o InsertionSort
gcc SelectionSort.c -o SelectionSort
gcc DuplicateElement.c -o DuplicateElement
gcc DuplicateElement2.c -o DuplicateElement2
gcc TwoPointerProblem.c -o TwoPointerProblem
