    <section>
      <h2>Files &amp; what they do</h2>
      <ul>
        <li><code>BubbleSort.c</code> — classic bubble sort (simple, educational, not for huge datasets).</li>
        <li><code>EnhancedBubbleSort.c</code> — bubble sort with an optimization (stops early if already sorted).</li>
        <li><code>InsertionSort.c</code> — insertion sort (great for small or nearly-sorted arrays).</li>
        <li><code>SelectionSort.c</code> — selection sort (easy to reason about; steady but not speedy).</li>
        <li><code>DuplicateElement.c</code> — finds duplicate elements in an array (teaches scanning and set-like logic).</li>
        <li><code>DuplicateElement2.c</code> — another variant / approach to detect duplicates.</li>
        <li><code>TwoPointerProblem.c</code> — a two-pointer technique example (useful pattern for sorted arrays, sums, etc.).</li>
        <li><code>test.cpp</code> — a small C++ test file (probably for trying things out).</li>
        <li><code>*.exe</code> files — precompiled binaries (handy on Windows; source files are preferred for learning).</li>
      </ul>
