What this repo is

A compact collection of sorting algorithm implementations and small array problem solutions written in C (with one tiny test.cpp for experimentation). Great for learning, comparing behavior, and practicing C compilation. Perfect for beginners who like watching numbers move in neat order.

Files & what they do

BubbleSort.c — classic bubble sort (simple, educational, not for huge datasets).

EnhancedBubbleSort.c — bubble sort with an optimization (stops early if already sorted).

InsertionSort.c — insertion sort (great for small or nearly-sorted arrays).

SelectionSort.c — selection sort (easy to reason about; steady but not speedy).

DuplicateElement.c — finds duplicate elements in an array (teaches scanning and set-like logic).

DuplicateElement2.c — another variant / approach to detect duplicates.

TwoPointerProblem.c — a two-pointer technique example (useful pattern for sorted arrays, sums, etc.).

test.cpp — a small C++ test file (probably for trying things out).

*.exe files — precompiled binaries (handy on Windows; source files are preferred for learning).

If you want more sorting algorithms (Merge, Quick, Heap, Counting, Radix, Shell), I can add them — say the word and I’ll scaffold them with nice comments and examples.
